2 · Comparaisons

Je veux…Exemple
Vérifier l’égalité5 == 5 // true
Vérifier la différence5 != 7 // true
Vérifier « plus petit »5 < 7 // true
Vérifier « plus grand »5 > 7 // false
Vérifier « plus petit ou égal »5 <= 5 // true
Vérifier « plus grand ou égal »5 >= 7 // false
Comparer deux chaînes"salut" == "Salut" // false
À retenir

= et <= incluent l’égalité. = affecte une valeur; == compare. Les majuscules et les espaces comptent dans les chaînes.

3 · if, else et else if

let score = 75;

if (score >= 90) {
    document.querySelector(".message").textContent = "Excellent !";
}
else if (score >= 60) {
    document.querySelector(".message").textContent = "Réussi !";
}
else {
    document.querySelector(".message").textContent = "À reprendre";
}
À retenir

Une seule branche de cette chaîne s’exécute : la première dont la condition est vraie. else n’a pas de condition; il est facultatif. On peut avoir plusieurs else if. Les conditions sont entre parenthèses, les instructions entre accolades.

let temps = 21;

if (temps > 15) {
    console.log("J’attends.");
}
if (temps > 20) {
    console.log("C’est long !");
}
À retenir

Plusieurs if indépendants sont tous vérifiés. Ici, les deux messages s’affichent.

4 · Vérifier une classe

if (document.querySelector(".texte").classList.contains("sobre")) {
    document.querySelector(".texte").textContent = "Classe sobre présente";
}
else {
    document.querySelector(".texte").textContent = "Classe sobre absente";
}
À retenir

contains("sobre") donne true ou false. Le nom de classe s’écrit sans point.

5 · Opérateurs logiques

Je veux…Exemple
Exiger les deux conditions : ETage >= 18 && age < 30
Accepter au moins une condition : OUage < 4 || age > 99
Inverser un booléen : NON (complément)!(age < 4 || age > 99)
Comparer trois couleurscouleur1 == couleur2 && couleur2 == couleur3
À retenir

Écrire chaque comparaison au complet : age >= 18 && age < 30. || contient deux barres verticales. ! inverse vrai et faux; il est plutôt en complément.

let age = 21;
if (age >= 18 && age < 30) {
    console.log("Jeune adulte");
}

6 · Priorités

À retenir

Du premier au dernier : parenthèses () → inverse ! → * / → + - → comparaisons → && → || → affectation =. Utiliser des parenthèses pour rendre une condition claire.

let resultat = (5 + 3) * 2 >= 10 && 4 < 9; // true

Lire le message et la ligne indiquée dans la console, corriger, puis tester à nouveau. Vérifier aussi le résultat visible dans la page.

1 · Répéter avec while

Je veux…Exemple
Répéter tant que la condition est vraiewhile (condition) { /* instructions */ }
Vérifier la condition avant chaque passagewhile (i < 4) { /* instructions */ }
let i = 1;

while (i < 4) {
    console.log(i);
    i += 1;
}
// Affiche 1, 2, 3
À retenir

La boucle while vérifie sa condition avant chaque itération. Quand elle devient false, la boucle s'arrête. Si la condition est fausse dès le départ, les instructions ne s'exécutent pas.

2 · Compteur et nombre d’itérations

Je veux…Exemple
Commencer à 1let i = 1;
Recommencer tant que i est plus petit que 4while (i < 4) { /* instructions */ }
Augmenter le compteuri += 1;
Répéter 9 fois, de 1 à 9while (i < 10) { /* instructions */ }
let i = 1;
let texte = "";

while (i < 10) {
    texte += i;
    i += 1;
}
// 9 itérations : i vaut 1, 2, ..., 9
À retenir

Pour construire une boucle, repérer ce qui change à chaque répétition : valeur initiale du compteur, condition d'arrêt et modification du compteur. Ici, i augmente de 1 à chaque itération.

3 · Accumuler une valeur

let valeur = 10;
let i = 1;

while (i < 5) {
    valeur += i;
    i += 1;
}
// valeur vaut 20 : 10 + 1 + 2 + 3 + 4
À retenir

À chaque itération, += ajoute une valeur à celle qui est déjà conservée. Cette boucle effectue quatre itérations.

4 · Répéter une opération sur le DOM

Je veux…Exemple
Construire un nom de classe avec le compteur".bob" + i
Retrouver l’élément qui corresponddocument.querySelector(".bob" + i)
Ajouter une classe à cet élémentdocument.querySelector(".bob" + i).classList.add("image");
let i = 1;

while (i < 4) {
    document.querySelector(".bob" + i).classList.add("image");
    i += 1;
}
À retenir

Le compteur sert à cibler successivement .bob1, .bob2 et .bob3. La classe image est ajoutée à chaque élément, sans recopier trois fois l'instruction.

5 · Éviter une boucle infinie

// Exemple à NE PAS exécuter tel quel :
let i = 1;

while (i < 4) {
    console.log("Oups ! Boucle infinie.");
    // Il manque : i += 1;
}
À retenir

Si i ne change jamais, la condition i < 4 reste toujours vraie : la boucle peut figer la page. Prévoir une condition qui pourra devenir fausse et mettre à jour les variables nécessaires.

6 · Conditions dans une boucle

let i = 1;

while (i < 4) {
    if (i == 2) {
        console.log("Deuxième passage");
    }
    i += 1;
}
À retenir

Un bloc if peut se trouver dans une boucle while. Sa condition est évaluée à chaque itération.

7 · Plusieurs conditions avec &&

let x = 1;
let y = 10;

while (x < 5 && y > 5) {
    x += 1;
    y -= 2;
}
// La boucle s'arrête avec x = 4 et y = 4.
À retenir

Avec && (ET), toutes les conditions doivent rester vraies. La boucle s'arrête dès que l'une devient fausse : ici, y atteint 4 alors que x est encore plus petit que 5.

8 · Pour aller plus loin (facultatif)

do {
    // Instructions
} while (condition);
À retenir

La boucle do...while vérifie sa condition APRÈS les instructions : elle s'exécute donc au moins une fois. Elle est facultative dans Z03 et n'est pas exigée aux évaluations. La section sur le débogueur est elle aussi entièrement optionnelle.

Je veux…Exemple

Initialiser le compteur → vérifier la condition → exécuter les instructions → faire évoluer le compteur. Éviter les boucles infinies. do...while et le débogueur sont facultatifs.

6 · Ajouter et retirer des éléments

// [68, 71, 93]
let couleurs = ["Bleu", "Rouge", "Jaune",

couleurs.splice(0, 2);

À retenir

push ajoute à la fin; pop retire le dernier élément. splice(indexDépart, nombreÀRetirer) supprime des éléments consécutifs, en commençant à l'index indiqué.

9 · Rechercher une valeur

On peut utiliser if dans une boucle pour examiner chaque valeur du tableau et réagir si une condition est vraie.
