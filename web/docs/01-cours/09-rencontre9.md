## Noyau prévu

- comprendre le rôle du DOM à un niveau introductif;
- sélectionner un élément avec `querySelector`;
- lire et modifier `textContent`;
- conserver un élément HTML dans une variable lorsque cela simplifie le code;
- lire ou modifier un attribut concret lorsque requis.
