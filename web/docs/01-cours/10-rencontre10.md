# Rencontre 10 - Événements et classes CSS avec le DOM

:::warning Séquence provisoire
Cette rencontre reprend l'ancien contenu sur les événements et les styles DOM, mais le noyau devra privilégier `addEventListener` et les classes CSS plutôt qu'une longue liste de styles écrits directement en JavaScript.
:::

## Noyau prévu

- écouter un clic avec `addEventListener`;
- appeler une fonction lorsqu'un événement se produit;
- ajouter, retirer ou basculer une classe avec `classList`;
- modifier une propriété simple directement seulement lorsque cela est pertinent;
- consolider les fonctions et le DOM.
