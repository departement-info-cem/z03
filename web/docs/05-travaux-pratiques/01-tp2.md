Vous allez compléter le JavaScript d'un jeu de **Roche-Papier-Ciseaux** pour **deux joueurs**. Le travail progresse des **rencontres 7 à 10**.

:::info 📥 Fichier à télécharger
**[Télécharger `tp2-roche-papier-ciseaux-etudiants.zip`](pathname:///files/travaux-pratiques/tp2-roche-papier-ciseaux-etudiants.zip)**

Enregistrez le ZIP dans votre dossier de cours, puis extrayez-le avant de commencer.
:::

## Pour commencer

Ouvrez le dossier extrait `TP2_Etudiants` dans **VS Code**, puis `index.html` dans votre **navigateur**.

Pour toutes les missions, les points, les indices et la remise, ouvrez **`ENONCE_TP2.html`** inclus dans le ZIP.
