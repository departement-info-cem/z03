**[Consulter l'aide-mémoire complet R6–R12](pathname:///files/aide-memoire/aide-memoire-javascript-r6-r12.html)**

Ce document rassemble les notions de JavaScript enseignées des rencontres **6 à 12** dans **un seul aide-mémoire HTML**. Son sommaire intégré permet d'aller directement à une rencontre, puis à la rubrique recherchée.

Il couvre les variables, le DOM, les fonctions, les événements, les conditions, les opérateurs logiques, les paramètres, les retours, les boucles et les tableaux. Les notions facultatives déjà identifiées dans le document conservent leur statut.

## Pour consulter le fichier sans Internet

Ouvrez l'aide-mémoire complet, puis enregistrez le fichier HTML sur votre ordinateur. Vous pourrez ensuite l'ouvrir dans un navigateur sans connexion Internet ou l'imprimer avec **Ctrl+P** (ou **Cmd+P**).

Vous pouvez aussi utiliser la page **[Téléchargements](./04-telechargements.md)**.

:::info Documentation permise à l'examen

Cet aide-mémoire est une **ressource de révision**. L'enseignant précisera séparément si ce document est autorisé à l'examen.

:::
