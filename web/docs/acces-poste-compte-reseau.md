# Accès au poste et compte réseau

Avant de commencer à coder, vous devez pouvoir **ouvrir une session sur un ordinateur du Cégep** et accéder aux services institutionnels nécessaires au cours.

:::info À faire avant de commencer
Si votre compte réseau n'est pas encore activé ou si votre mot de passe ne fonctionne pas, réglez cette situation dès que possible. Plusieurs activités du cours supposent que vous pouvez ouvrir votre session et accéder à vos fichiers.
:::

## Le compte réseau

Le **compte réseau** est le compte utilisé notamment pour accéder :

- aux ordinateurs du Cégep;
- au réseau sans fil;
- à Microsoft 365 / Office 365;
- au courriel étudiant;
- à différents services et applications du Cégep.

Pour la procédure officielle de première activation, de gestion du mot de passe ou de compte verrouillé, utilisez toujours la documentation du Cégep :

**[Consulter la procédure officielle — Compte réseau](https://techno.cegepmontpetit.ca/compte-reseau/)**

Les détails de cette procédure peuvent changer. Cette page du cours vous indique donc **où aller**, plutôt que de recopier ici toutes les étapes techniques.

## Double authentification (2FA)

Le Cégep utilise aussi la **double authentification (2FA)** pour les comptes étudiants. Elle ajoute une deuxième vérification lors de certaines connexions aux services du Cégep.

**[Consulter la procédure officielle — Double authentification (2FA) pour les étudiants](https://techno.cegepmontpetit.ca/cybersecurite/2fae/)**

:::tip Préparez-la avant d'en avoir besoin
Si une configuration 2FA vous est demandée, faites-la avant de commencer une activité où vous devez accéder à Microsoft 365, OneDrive ou à un autre service institutionnel.
:::

## Si vous n'arrivez pas à ouvrir votre session

Ne créez pas un nouveau compte et ne changez pas plusieurs réglages au hasard.

1. consultez d'abord la section appropriée de la page **Compte réseau**;
2. vérifiez si le problème concerne l'activation, le mot de passe ou un compte verrouillé;
3. si le problème persiste, utilisez les coordonnées d'aide indiquées dans la documentation technologique du Cégep.

**[Consulter l'aide technologique du Cégep](https://techno.cegepmontpetit.ca/besoin-daide/)**

## Avant de continuer

Vérifiez que vous pouvez faire les actions suivantes :

- [ ] ouvrir une session sur un ordinateur du Cégep;
- [ ] utiliser votre mot de passe réseau;
- [ ] compléter la double authentification lorsqu'elle est demandée;
- [ ] accéder aux services Microsoft 365 nécessaires au cours.

Une fois votre accès fonctionnel, la prochaine étape consiste à préparer vos dossiers et vos outils de travail.
