# Ouvrir un projet et se repérer dans VS Code

Avant de commencer à écrire du HTML ou du CSS, il faut surtout savoir **ouvrir le bon dossier de projet et retrouver ses fichiers**.

Cette capsule présente les gestes essentiels pour commencer à travailler dans Visual Studio Code sans faire le tour de toutes ses fonctionnalités.

## Ce que vous allez voir

En quelques minutes, vous verrez comment :

- ouvrir le **dossier complet d'un projet** dans Visual Studio Code;
- repérer l'**Explorateur**, où apparaissent les fichiers et les dossiers du projet;
- créer un **nouveau fichier**;
- créer un **nouveau dossier**;
- ouvrir un fichier dans l'éditeur et savoir **où écrire ou modifier le code**.

L'objectif n'est pas de connaître toute l'interface de Visual Studio Code. Il suffit de maîtriser ces quelques repères pour pouvoir commencer à travailler sur un projet Web.
